## 🌟 Overview

A luxury editorial, interaction-rich personal portfolio engineered with semantic HTML5, modern vanilla CSS, and vanilla JavaScript. Features a layered depth hero stage, interactive MacBook laptop chassis mockups, dynamic role typewriter, interactive 3D lanyard student ID card, and fluid mobile responsiveness.

---

## ✨ Key Features

- **Editorial Hero Section**: Centered depth-layered cutout portrait that overlaps dynamically behind italic serif typography with real-time typewriter role cycling.
- **MacBook Retina Laptop Mockups**: High-fidelity 16:10 laptop chassis with metallic space-gray bezels, optical lens glare reflections, and aluminum lip thumb-notches showcasing live web apps.
- **Suspended Acrylic ID Card**: Interactive, floating student ID badge (#DR-MCET-2024-28) featuring a physics-inspired lanyard dangle.
- **Multi-Theme Engine**: Seamless real-time switching between **Light**, **Dark**, and **Obsidian** luxury color schemes with persistent state.
- **Certificate Lightbox & Credibility Bar**: Interactive modal viewing verified inter-college awards (Techwala'26, Nexora'26) and coursework.
- **Mobile-First Responsive Design**: Optimized across mobile viewports (iPhone 16, Android, iPad, Retina desktop).

## 💻 Local Development Setup

To run this portfolio locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Rithi0186/portfolio.git
   cd portfolio
   ```

2. **Serve the project:**
   You can use any static local server. For example, using Python:
   ```bash
   python3 -m http.server 5050
   ```
   Or using Node.js:
   ```bash
   npx serve .
   ```

3. **Open in browser:**
   Navigate to `http://localhost:5050` (or the port shown in your terminal).
